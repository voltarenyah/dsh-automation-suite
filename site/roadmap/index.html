Roadmap

Where it stands today

An early build. Statuses follow the repository roadmap, and nothing planned is presented as shipped.

01

Maturity

The three layers, as they actually are.

Access

Block export and import, compile and project data work on real projects. Twenty operations added in v0.2 are still unverified in the field.

Partial

Semantics

XML to SQLite graph works on fixtures. Freshness, incremental updates and a compatibility layer are not done.

Prototype

Governance

The Git tools are general-purpose. The version workflow is two steps: sync the source tree, then commit it.

Partial

02

Compatibility

What it runs on today.

Operating system
Windows for the TIA tools. Other platforms can load the plugins, but TIA calls fail.
DeepSeek Harness
Any version that can load bundles; built and tested against 0.2.1-rc.2.
TIA Portal
V17 only — V16 and V18 are not compatible.
Node.js
22.19 or newer.
Openness
Siemens.Engineering.dll from Portal V17, and membership in the local “Siemens TIA Openness” group.
