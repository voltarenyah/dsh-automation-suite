# dsh-automation-suite 0.2.1 — DPI and icon hotfix

This is a hotfix for **0.2.0**. It changes no profile/plugin content and no
installer flow; it fixes the desktop shell's visual presentation.

## Fixed

- **Low-resolution / blurry UI**: the shell project declared
  `ApplicationHighDpiMode=PerMonitorV2`, but `Program.cs` did not call
  `Application.SetHighDpiMode(...)`, so the process stayed system-DPI-aware and
  Windows bitmap-scaled the window. The shell now explicitly sets
  `HighDpiMode.PerMonitorV2` before creating any window; the process reports
  `awareness=2`.
- **Missing application icon**: added `desktop/DshSuite.Shell/app.ico` with
  16/24/32/48/64/128/256 sizes. The exe, window, tray icon, installer, desktop
  shortcut and uninstall entry now use it instead of the default .NET icon.

## Verification

- 0.2.1 installer silent install + fixed profile + shell smoke: pass.
- Shell process DPI awareness: `2` (per-monitor).
- Embedded icon extracted from both `DshSuite.Shell.exe` and the setup exe.
- Visual check on the host: icon and DPI are correct.

The functional acceptance from 0.2.0 (clean Windows 11 LTSC VM, DSH/WebView2
bootstrap, profile, doctor, shell smoke, uninstall) is unchanged.

## Upgrade

Exit the running app, then run this setup with the same `DSH_HOME` used by 0.2.0
(or let it use the default). The installer updates the shell/app layer and keeps
the fixed profile; previous `cordis.patch.yml` overrides are backed up and merged.
