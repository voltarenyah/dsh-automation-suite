# dsh-automation-suite 0.1.5

**发布日期：2026-11-07** · **最后一个以 Web 方式启动的版本**

0.1.5 仍是“本机 Web UI”：`start.cmd` 启动 DSH 的 Web profile，用系统浏览器打开
`http://127.0.0.1:<port>/?token=…`，控制台窗口保留；桌面壳与安装器从下一阶段开始。

## 这个版本带来什么

### 新增 doctor：先告诉你能用什么

安装末尾会自动运行 `doctor.ps1`，解压目录里也有可双击的 `doctor.cmd`。它报告：

| 检查 | 说明 |
|---|---|
| DSH / profile / 插件行 | 合并后的 profile 是否能真正加载 |
| 图谱引擎 `--self-test` | 原生 SQLite + 解析 + 只读闸门；不依赖系统 .NET |
| .NET Framework 4.8 | TIA / PLCSIM 控制器的前提 |
| TIA Portal V17 | Openness DLL + 当前用户是否在 `Siemens TIA Openness` 组 |
| PLCSIM Advanced | API 4.0 是否存在 |
| Git | `git.exe` 是否可用 |
| 图纸 / Excel | pdfium WASM、unpdf、xlsx、fast-xml-parser 是否装上 |
| 模型凭据 | 首次启动仍需自己配 API key |

输出 `[ OK ]` / `[WARN]` / `[FAIL]`：只有 `[FAIL]` 会阻止启动；`[WARN]` 表示对应能力暂不可用。
`doctor.ps1 -Json` 是给桌面安装器复用的机器可读契约。

### 图谱引擎不再要求用户安装 .NET

`dsh-engineering-graph` 从 net8.0 升到 **.NET 10 LTS**，发布 tarball 里是 **self-contained
win-x64 单文件**（约 39 MB）。TIA Portal 只提供 .NET Framework 4.8、DSH 只提供 Node，
所以旧版实际上要求用户为一个插件单独装 .NET 8；0.1.5 起不再需要。仓库里的
`engine/bin` 仍是开发/测试用的 framework-dependent 构建，维护者重新构建需要 .NET 10 SDK。

### Changes 面板（P1，只读）

右侧栏新增 **Changes**：按会话工作目录读取真实 git 状态，列出未提交文件与每文件
`+N/−M`，面板可见时每 5 秒刷新。**提交区（P2）尚未实现**，这个版本只读。
数据来自宿主的一条只读路由 `GET /changes/api/status`，不写工作区、不执行提交。

### 0.1.4 之后补齐的插件

`dsh-drawing`（电气图纸）、`dsh-ui-versions`（版本历史）、`dsh-ui-hardware`（硬件机架）、
`dsh-ui-prompt-guide`（Prompt Guide）、`dsh-ui-project-dashboard`（工作区面板）、
`dsh-ui-changes`（Changes）全部进入发行版：**13 个本地插件 + `dsh-opencode-go`**。
`--dump-config` 为 **2090 行 / 14 个插件行**（DSH 0.2.1-rc.2，全新 profile）。

## 安装

1. 下载 `dsh-automation-suite-0.1.5.zip`；
2. 解压后双击 `install.cmd`（推荐；不要直接双击 `.ps1`，MOTW 会让窗口一闪而过）；
3. 安装末尾看 doctor 的能力表；
4. 双击 `start.cmd`，浏览器打开本机 Web UI；
5. 首次进入在 **设置 → Models** 填 API key。

默认使用专用 home `%USERPROFILE%\dsh-automation-suite-home`，默认 profile
`dsh-automation-suite-v0.1.5`；与日常 `~/.dsh` 完全隔离。

## 从旧版本升级

- **并存（推荐）**：解压新 zip 到新目录 → `install.cmd` → 用新目录的 `start.cmd`。
  新 profile 与旧 profile 并存；API key、workspace 注册表、会话目录都在同一个 `DSH_HOME` 下，会保留。
- **profile 级设置不会自动迁移**：旧 profile 的 `cordis.patch.yml` 里应用回写的设置
  （`requestTimeoutMs`、模型可见性等）需要复核/重设。固定 profile 原地升级可用
  `install.ps1 -Profile <名字> -Force`，它会先备份 `package.json` / `cordis.patch.yml`，
  但仍需从备份合并用户覆盖项。
- **回退**：用旧目录的 `start.cmd`，或 `dsh --profile dsh-automation-suite-v0.1.4`。

## 已知限制

- TIA 部分仅 Windows + TIA Portal V17；需要 Openness DLL、.NET Framework 4.8，
  当前用户在 `Siemens TIA Openness` 本地组里。
- PLCSIM 功能需要 PLCSIM Advanced API 4.0。
- Git 工具需要 `git.exe`；doctor 会报告缺失。
- Excel/PDF 不需要 Office/Acrobat，但安装时 npm 依赖需要访问 registry。
- 首次安装有网络依赖：十三个 tarball（约 34 MiB）+ npm 依赖。
- 没有自动更新：升级 = 下载新版本并重跑安装。
