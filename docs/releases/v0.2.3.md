# dsh-automation-suite 0.2.3 — home branding, Chinese UI, in-app picker

This release updates plugin content and one profile composition; the installer
flow is unchanged.

## Added

- **Home hero branding** (`dsh-ui-brandmark`): the landing headline is now
  `dsh-automation-suite`, the badge is `TIA-V17`, and the mark is the desktop
  shell's app icon (128 px PNG taken from `desktop/DshSuite.Shell/app.ico` and
  inlined as a data URL at build time). Only the two `conversation` keys
  (`hero.headline`, `hero.preview`) are overridden; every other string falls
  through to the stock dictionaries, and the mark occupies the existing
  `conversation.hero.brand.mark` slot instead of the whale fallback.
- **Distinct guide icons** for the five suite tabs on the right sidebar's start
  page: PLC Blocks, Versions, Changes, Hardware and Drawings each ship their own
  36-viewBox artwork, instead of the generic cube the start page shows when a
  tab type has no icon.
- **Chinese sidebar names**: `Prompt Guide` → `提示词引导` and
  `Project Dashboard` → `项目看板`. The prompt-guide client now registers a
  dictionary and binds its rail label and iframe title through the locale
  service; the page's heading, title and meta line follow the app language too.

## Changed

- **In-app directory picker**: the suite profile disables upstream
  `dsh-host-directory-picker-auto` and pins the browse pair
  (`dsh-host-directory-picker-browse` + `dsh-client-ui-directory-picker-browse`).
  "Add workspace" now always opens the in-app "Select Workspace Directory"
  surface — on the loopback desktop/dev env as well as for remote/SSH clients —
  instead of the Windows folder dialog. The installer and `start-env` read the
  same profile composition.

## Verification

- `pnpm -r test` (16 packages, all green), `pnpm -r build`, `pnpm -r typecheck`.
- `build-app-layer.mjs --version 0.2.3`: offline `--dump-config` + doctor.
- 0.2.3 silent install + fixed profile + shell `--smoke-test`.
- Manual preview under a zh-CN client: branded hero, Chinese sidebar, in-app
  picker, and five distinct tab icons.

## Upgrade

Exit the running app, then run this setup with the same `DSH_HOME` used by the
previous version (or let it use the default). The installer updates the shell and
app layer and keeps the fixed profile; previous `cordis.patch.yml` overrides are
backed up and merged.
