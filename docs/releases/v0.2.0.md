# dsh-automation-suite 0.2.0 — desktop installer

This is the first **desktop installer** release of dsh-automation-suite. It
installs the WebView2 shell, a materialized fixed profile, the local plugins,
and the graph engine; it does not require npm/pnpm at install time.

## Requirements

- Windows 10/11 x64.
- Internet access during setup if DSH or WebView2 is missing (they are downloaded
  from the official sources and verified).
- TIA Portal V17 / PLCSIM are **not bundled**; the suite reports their state via
  doctor and the TIA plugin still requires a local TIA installation.

## What setup does

1. Materializes the app layer under `%LOCALAPPDATA%\dsh-automation-suite\app\0.2.0`.
2. If `dsh.cmd` is missing, downloads the official DSH installer, verifies its
   SHA-512 and DeepSeek Authenticode signature, installs it silently, and waits
   for `dsh.cmd`.
3. If WebView2 Runtime is missing, downloads the Evergreen Bootstrapper and
   installs it.
4. Copies `app\0.2.0\profile` to the fixed profile
   `%USERPROFILE%\dsh-automation-suite-home\profiles\dsh-automation-suite`.
5. Merges previous user overrides from `cordis.patch.yml` with the new baseline
   and keeps a `.bak-<stamp>` copy.
6. Writes `install.json` / `current.txt` and runs `doctor.ps1 -Json`.
7. Creates the desktop/Start Menu shortcuts and the uninstaller.

## Verified acceptance

Clean VM: **Windows 11 Enterprise LTSC 2024 Evaluation**, initially with no DSH
and no WebView2.

```text
install exit              0
DSH install               0.2.2-rc.1 (silent; SHA-512 + Authenticode)
WebView2 bootstrap        157.0.4341.42
install.json              present
fixed profile             present
current.txt               present
doctor                    8 OK / 4 WARN / 0 FAIL
shell --smoke-test        ok=true, navigation=completed
uninstall                 install dir removed, DSH_HOME retained
```

The DSH download path was additionally verified with
`bootstrap-dsh.ps1 -VerifyOnly` against the live official feed.

## Known limitations

- The installer is **unsigned**; Windows SmartScreen may show “Unknown
  publisher”. Use “More info → Run anyway” for this build.
- **No auto-update.** Upgrade by running a newer setup; it keeps the DSH_HOME and
  the user's profile overrides. Previous app layers are kept side-by-side.
- DSH version policy is not implemented yet: an existing DSH is used as-is and
  doctor warns if it differs from the tested version.
- Windows 10 was not separately acceptance-tested; the clean VM was Windows 11
  LTSC.
- TIA Portal / PLCSIM remain external prerequisites.

## Assets

- `dsh-automation-suite-setup-0.2.0.exe`
- `dsh-automation-suite-setup-0.2.0.exe.sha256`
- `desktop-manifest.json`

The installer is self-contained for the shell; DSH is downloaded only when
missing.
