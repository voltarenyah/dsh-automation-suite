TIA Portal Openness firewall / 应用白名单（手册同名章节）。 注册表键 HKLM\SOFTWARE\Siemens\Automation\Openness\<ver>\Whitelist\<App>.exe，含 Path / DateModified / FileHash。 手册：提示只在"连接到正在运行的 TIA Portal"时出现 —— 自启无界面实例不会触发。
E · 环境
同机装有基于 TIA Portal 的产品（如 STEP 7 Professional / WinCC Professional）与 TIA Portal Openness；手册另要求 .NET Framework SDK 4.8，并约定 remoting IpcChannel（ensureSecurity=false、priority=1、typeFilterLevel=Full）。
P · 实机
需要真实 PLC / PLCSIM、项目服务器或对应许可，无法在纯离线工程上验证。
D · 界面
依赖桌面交互：独占访问对话框、块编辑器、Devices & networks 编辑器等；无界面模式下行为不同或不可用。

手册明示的限制 / 直接拒绝

R0 · 无 API
手册 "Adding users to the \"Siemens TIA Openness\" user group"：加组无法通过 TIA Portal API 完成。
R1 · F 系统块
手册 "Exporting failsafe blocks"：F 块可以导入导出，**F-system 块不能导出**（工程实测 FOB_SAFETY 报 "export is not permitted"）。
R2 · 库对象
手册 "Exporting configuration data"：库中的对象类型不支持导出。
R3 · 集成连接
手册 "Exporting connections"：集成连接（integrated connections）不支持导出。
R4 · 多语言文本
手册 "Export of project texts"：多语言文本不能单独导出，只能随父对象一起导出。
R5 · 外部源组
手册 "Adding an external file" / "Deleting an external file"：External source files 组的组层级不可访问。
R6 · 地址属性
手册 "Accessing attributes of an address object"：压缩地址（packed addresses）在 Openness 中不支持；改地址不会重连已分配的标签。
R7 · 跨子树引用
手册 "Basic principles of importing/exporting"：非同一子树的被引用对象无法完整导入导出，只能以 open reference 形式进出。
R8 · 库版本状态
手册 "Accessing blocks located in library"：处于 in-work 状态的库版本数据不可导出。
R9 · 无批量导出
手册 "Exporting all screen templates of an HMI device" 等：不支持批量导出，必须逐个对象枚举后导出。
R10 · psc 分步
手册 "Creating and exporting psc file"：创建 .psc 与打开 .psc 不能分成两个命令执行。
R11 · 归档模式
